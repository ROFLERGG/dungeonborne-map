## Fan-made interactive map for Dungeonborne

An interactive map for the game Dungeonborne, allowing you to view locations, enemies, and bosses on the map.

## 🔗 Demo 
[https://dungeonborne-interactive-map.vercel.app](https://dungeonborne-interactive-map.vercel.app/)

## ✨ Features
- Interactive map with zoom and drag
- Switch between different locations
- Markers (bosses, enemies, exits)
- Pop-up information on click
- Filtering objects on the map

## 🛠 Tech Stack 
- React
- Next.js
- React Leaflet
- Tailwind CSS
